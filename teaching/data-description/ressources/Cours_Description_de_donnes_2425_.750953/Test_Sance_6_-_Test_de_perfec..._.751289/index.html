Description

Après chaque séance, vous devez réaliser des tests de perfectionnement en ligne sur la plateforme Moodle. Ces vous permettent de situer votre niveau et ils sont obligatoires. Les notes obtenues via ces tests sont prises en compte dans votre moyenne à hauteur de 10% de la note finale. Nous vous conseillons fortement de ne pas faire ces tests à l'avance, cela n'a pas d'intérêt et vous vous pénaliseriez !

Lorsque vous serez dans un test, vous trouverez sous chaque question un bouton "Vérifier" vous permettant de voir si la réponse choisie est la bonne. Si ce n'est pas le cas, alors vous pouvez réétudier la question et faire une autre proposition de réponse... ATTENTION CEPENDANT ! Tout essai de réponse erronée entraine une pénalité ! (-0,33% pour une question à choix multiple, -1pt pour une question "vrai/faux").

Par ailleurs, les tests restent ouverts afin que vous puissiez les faire autant de fois que nécessaire, pour vous entrainer et progresser. Mais attention : la note retenue sera bien celle de votre première tentative, celles reçues ensuite ne seront qu’indicatives.

Enfin, lorsque vous avez terminé un test, n’oubliez pas de cliquer sur « Terminer le Test » puis « Tout envoyer et terminer » en bas de la page récapitulative.
