# Implementation Plan: Mathematical Fundamentals — French Version

**Branch**: `008-math-fundamentals-french` | **Date**: 2026-09-17 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/008-math-fundamentals-french/spec.md`

**Note**: This plan was produced by the `/speckit-plan` command.

## Summary

Create a complete French-language version of the `teaching/mathematical-fundamentals/`
course (20 `.qmd` files) under `fr/teaching/mathematical-fundamentals/`, add a
per-page EN↔FR language switcher via an OJS include, and expand the existing
partial French sidebar block in `_quarto.yml` to cover all 20 pages. The
English course is the source of truth; all content is translated (no stubs)
in a single pass. No new build tools or dependencies are introduced.

## Technical Context

**Language/Version**: Quarto Markdown (`.qmd`) with YAML front matter; Quarto
CLI (version already installed in project).

**Primary Dependencies**: Quarto (sole content pipeline); `assets/dark.scss`
(HTML pages); `assets/dark-slides.scss` (RevealJS slides); OJS (already
supported by Quarto, used for language switcher).

**Storage**: Filesystem — 20 new `.qmd` files under
`fr/teaching/mathematical-fundamentals/`; one new `_metadata.yml`; one new
OJS include file; edits to `_quarto.yml`.

**Testing**: `quarto render` exit code 0; manual link-follow audit of the
French sidebar; visual check that the language switcher appears on EN and FR
pages and that clicking it lands on the correct counterpart.

**Target Platform**: GitHub Pages (static HTML output in `docs/`).

**Project Type**: Quarto website (static site).

**Performance Goals**: N/A — static site; rendering time is not a user-facing metric.

**Constraints**:
- No new runtime dependencies (no R, no npm packages, no Quarto extensions).
- `quarto render` must exit 0 before any commit touching `.qmd` sources or
  `_quarto.yml`.
- Both EN and FR render targets must pass (Principle VI + Development Workflow).
- All custom styling in `assets/dark.scss` only (Principle V).
- No inline `style=` attributes or `<style>` blocks (Principle V).

**Scale/Scope**: 20 French `.qmd` files + 1 `_metadata.yml` + 1 OJS include +
`_quarto.yml` sidebar/navbar changes.

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

- [x] **I. Content-First** — All 20 French pages are `.qmd` sources; no direct
  HTML in `docs/`. The OJS language switcher is a `.qmd` include file, not a
  raw HTML inject.
- [x] **II. Navigation registered** — The `fr-mathematical-fundamentals` sidebar
  block in `_quarto.yml` will be expanded to cover all 20 French pages. No
  French page is rendered without a sidebar entry.
- [x] **III. Reproducible** — French `.qmd` files contain no Python computation
  that requires re-execution; `_freeze/` entries are generated by `quarto render`
  and committed alongside source.
- [x] **IV. Privacy-First** — OJS language switcher computes a URL from
  `window.location.pathname`; no external calls, no cookies, no tracking.
- [x] **V. Styling contained** — No inline styles or `<style>` blocks. Any
  theme adjustments go in `assets/dark.scss` only.
- [x] **VI. Bilingual parity** — This feature *is* the bilingual parity
  implementation for the math fundamentals course. All 20 pages receive full
  French translations. Language switcher links EN↔FR on every page.
- [x] **T-I. Content Fidelity** — French translations preserve all canonical
  theory, worked examples, and exercises. Only prose is translated; LaTeX
  formulas are verbatim copies.
- [x] **T-II. Pedagogical Structure** — French modules follow the same
  theory → worked examples → exercises with collapsible solutions order.
- [x] **T-III. Audience language** — French prose targets undergraduate
  business-school students; every formula retains its plain-language
  explanation (translated).
- [x] **T-IV. Interactive demos** — OJS/Shinylive blocks are carried over
  from the English source with prose labels translated. Any widget with no
  user-visible prose is copied verbatim.
- [x] **T-V. Glossary** — A complete French `glossary.qmd` is delivered
  with parity entries to the English glossary.
- [x] **T-VI. Proof** — Collapsible formal proofs from English modules are
  carried over in French.
- [x] **T-VII. Visual intuition** — Geometric interpretations from English
  modules are preserved in French translations.
- [x] **T-VIII. Course syllabus** — `fr/teaching/mathematical-fundamentals/
  index.qmd` serves as the French syllabus; it is the first entry in the
  French sidebar block; it contains a Recommended Literature section with
  author/title/edition/publisher for each reference.
