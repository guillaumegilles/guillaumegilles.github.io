# Implementation Plan: Interactive Surendettement Map — Hybrid Cartography for the overindebtedness Post

**Branch**: `016-interactive-surendettement-map` | **Date**: 2026-11-20 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/016-interactive-surendettement-map/spec.md`

## Summary

Replace the four static matplotlib choropleths in the cartography section
of `posts/overindebtedness/index.qmd` with one interactive map explorer
(native `{ojs}` block: year slider + play, 6-indicator selector, 4 display
modes, hover tooltip, click-to-pin sparkline panel, top-5 risers/fallers
labels, keyboard/screen-reader support, collapsible data table), keeping
one static hero map as no-JS fallback plus a rebound variation map as the
post preview image. Fix the encoding (filing rate per 10,000 inhabitants,
quantile classes, diverging scale centered on 0). Fix the BdF pipeline so
the year range is dynamic and 2018 is attempted from the official annual
synthesis (API floor is 2019-01, verified — see research.md). Geometry is
inlined as quantized TopoJSON (~83 KB measured) so the widget makes zero
runtime network requests (constitution IV) within the ≤ ~200 KB payload
budget.

## Technical Context

**Language/Version**: Python 3.11 (`.venv/`) for the data pipeline and the
build-time data preparation chunk; Observable JS in a native Quarto
`{ojs}` block for the widget; Quarto 1.10.19 (installed) renders the site.

**Primary Dependencies**: pandas 2.3.3, geopandas 0.14.4, matplotlib 3.10.8,
requests 2.33.1, pdfplumber (already in `.venv`) — all in root
`requirements.txt`; **new build-time dependency**: `topojson` (Python) for
geometry quantization (add to `requirements.txt`; installed in `.venv` for
research). Client-side, only libraries bundled with Quarto OJS are allowed:
`d3` (v7 bundle, includes d3-topojson and d3-geo), `Plot`, `Inputs` — no
jsdelivr/CDN imports (privacy, FR-017).

**Storage**: files only — `posts/overindebtedness/data/processed/*.csv`,
`data/geo/departements.geojson`, raw sources under `data/raw/`; render
cache in `_freeze/` (committed). No database.

**Testing**: no unit-test framework in this repo; validation is (a) the
data-contract script `posts/overindebtedness/scripts/04_validate.py`
(coverage report), and (b) the runnable acceptance scenarios in
[quickstart.md](quickstart.md) mapped to SC-001…SC-010, plus the render
gate (`quarto render` exit 0).

**Target Platform**: static HTML served by GitHub Pages from `docs/`,
produced by `quarto render` (execute `freeze: auto` set in `_quarto.yml`).

**Project Type**: Quarto website — single blog post
(`posts/overindebtedness/index.qmd`); no new page, no new route.

**Performance Goals**: inlined widget payload ≤ ~200 KB (plan estimate
~115 KB: TopoJSON 83 KB measured + data ~30 KB); map recolors in < 100 ms
per control change on a laptop; rendered page has no console errors.

**Constraints**: zero runtime third-party requests from the widget
(constitution IV, FR-017); render gate `quarto render` exit 0 with `_freeze/`
committed (FR-021); prose in `.qmd` wrapped at 80 chars; no inline `style=`
or page-level `<style>` blocks for the widget — CSS classes in
`assets/custom.scss` only (FR-018); all map UI text in French.

**Scale/Scope**: 96 metropolitan departments × up to 8 years (2018/2019 →
latest complete year) × 6 indicators ≈ ≤ 4,600 values; one page; one
widget.

- [x] **IV. Privacy-First** — Widget makes zero runtime network requests:
  geometry + data inlined at build time via `ojs_define` (FR-017);
  client-side only Quarto-bundled libraries (no CDN imports); SC-004

- [x] **V. Styling contained** — Widget chrome (controls, tooltip, panel,

  `assets/custom.scss`; the `.qmd` gets no inline `style=` and no `<style>`

  attributes, not `style=` properties. Any added callout respects the
  allowed roles (note/tip/caution/warning/important).
- [x] **VI. Bilingual parity** — N/A for this feature: it modifies an
  existing post and creates no new page; the `fr/posts/` tree does not
  exist yet in this repo (pre-existing site state, flagged for governance —
  not introduced by this feature).

*Teaching-page gates T-I…T-VIII*: N/A — this is a blog post, not a teaching
