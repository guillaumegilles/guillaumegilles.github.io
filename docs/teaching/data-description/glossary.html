Glossary

Data Description

Every mathematical symbol and named formula introduced across Sessions 1–12 is listed below, with its notation, a plain-language definition, a pronunciation guide (Greek letters only — this course uses no Greek-letter notation, since it follows the Excel-aligned sample conventions locked in data-model.md), and the session where it is first introduced.

Percentages and totals (Session 1–2)

Notation Name Plain-language definition Pronunciation (Greek only) Introduced in
\(p_i\) Percentage distribution Share of a total that item \(i\) represents, \(x_i/T\times100\%\) — Session 1
\(\Delta\%\) Percentage change Relative change between an old and a new value — Session 1
\(T\) Grand total Sum of all values in a range or all group totals — Session 1

Univariate position (Sessions 3–5)

Notation Name Plain-language definition Pronunciation (Greek only) Introduced in
\(n\) Sample size Number of observations/individuals — Session 3
\(k\) Number of modalities Number of distinct categories/classes of a variable — Session 3
\(n_i\) Absolute frequency Count of observations in modality/class \(i\) — Session 3
\(f_i\) Relative frequency Share of observations in modality/class \(i\), \(n_i/n\) — Session 3
\(h\) Class width Width of a class interval in a grouped frequency table — Session 4
\(N_i^{+}\) Increasing cumulative frequency (count) Running total of counts up to and including class \(i\) — Session 4
\(F_i^{+}\) Increasing cumulative frequency (share) Running total of relative frequencies up to class \(i\), \(N_i^{+}/n\) — Session 4
\(Me\) Median The value splitting an ordered series into two equal halves — Session 5
\(Q_1, Q_2, Q_3\) Quartiles Values splitting an ordered series into four equal quarters (\(Q_2=Me\)) — Session 5
\(P_p\) Percentile Value such that approximately \(p\%\) of observations are \(\leq\) it — Session 5
\(IQR\) Interquartile range \(Q_3-Q_1\); spread of the central 50% of the data — Session 5

Univariate center, dispersion, and shape (Sessions 6–8)

Notation Name Plain-language definition Pronunciation (Greek only) Introduced in
\(\bar{x}\) Sample mean Arithmetic average of all observations, \(\frac{1}{n}\sum x_i\) “x-bar” Session 6
\(Mo\) Mode Most frequent value, or the center of the most frequent class for grouped data — Session 6
\(L, f_0, f_1, f_2\) Grouped-mode inputs Modal class lower bound, and the frequencies of the preceding/modal/following classes — Session 6
\(s^2\) Sample variance Average squared distance of observations from the mean, \(\frac{1}{n-1}\sum(x_i-\bar{x})^2\) — Session 7
\(s\) Sample standard deviation \(\sqrt{s^2}\); dispersion in the original unit — Session 7
\(CV\) Coefficient of variation Unit-free relative dispersion, \(s/\bar{x}\times100\%\) — Session 7
\(SKEW\) / \(g_1\) Fisher-Pearson sample skewness Bias-corrected, unit-free measure of asymmetry around the mean (Excel’s SKEW) — Session 8
Pearson asymmetry coefficient Pearson skewness coefficient \((\bar{x}-Mo)/s\); compares the mean to the mode — Session 8
\(YK\) Yule-Kendall skewness coefficient \((Q_3+Q_1-2Me)/(Q_3-Q_1)\); asymmetry from the five-number summary — Session 8

Bivariate (Sessions 10–11)

Notation Name Plain-language definition Pronunciation (Greek only) Introduced in
\(n_{ij}\) Contingency table cell count Count of individuals with modality \(i\) of one variable and modality \(j\) of the other — Session 10
\(n_{i\cdot}\), \(n_{\cdot j}\) Row / column margin Row or column total of a contingency table; recovers each variable’s own frequency table — Session 10
\(\text{Cov}(X,Y)\) Sample covariance Average product of deviations from each variable’s mean, \(\frac{1}{n-1}\sum(x_i-\bar{x})(y_i-\bar{y})\) — Session 11
\(r\) Correlation coefficient Unit-free strength/direction of the linear relationship between \(X\) and \(Y\), \(-1\le r\le1\) — Session 11
\(r^2\) Coefficient of determination Share of \(Y\)’s variability explained by a linear link with \(X\) — Session 11
\(a, b\) Regression intercept and slope Coefficients of the least-squares line \(\hat{y}=a+bx\) — Session 11
\(\hat{y}\) Predicted / fitted value The value of \(y\) predicted by the regression line for a given \(x\) — Session 11
