Data Description

MS03-001-G

Undergraduate course providing the fondamental mathematical intuition to understand, describe, and analyse data in finance, economics, and management.

Course description

Data Description introduces the basic statistical tools corresponding to the first stage of data analysis: numerical summaries and graphical representation of data, computed hands-on in Excel. By the end of the course, you will be able to take a raw column of business data — sales, weather, customer counts — and turn it into frequency tables, charts, and summary indicators that support a real business decision. A single running case study, “The Wandering Fork” (a fictional food-truck business), carries every worked example from Session 3 onward, so results build on each other across the whole course.

Curriculum placement

This course is the natural sequel to Mathematical Fundamentals (MS01, teaching/mathematical-fundamentals/) and Mathematical Analysis (MS02, teaching/mathematical-analysis/), and it is itself the prerequisite refresher for Inferential Statistics (MS04, teaching/decision-making-stat/), whose own Session 6 explicitly revisits the numerical summaries introduced here before moving on to confidence intervals and hypothesis testing.

Learning objectives

By the end of this course, you will be able to:

  1. Handle a spreadsheet fluently: cell referencing, sorting, PivotTables, and the basic Excel function library.
  2. Identify the nature of a variable and build the correct frequency table and chart for it.
  3. Compute and interpret position, central tendency, dispersion, and shape indicators for a quantitative variable.
  4. Build and read a contingency table and a scatter plot for two variables observed together.
  5. Compute and interpret covariance, correlation, and a simple linear regression line.
  6. Reproduce every computation with the correct English-locale Excel function.

Assessment

Examination % of overall grade Assessment mode Duration
Midterm Exam (ME) 35% Individual written, MCQ component 45 min
Final Exam (FE) 65% Individual written, MCQ component 90 min

Both exams cover Sessions 1–12; Session 12 closes the course with an original mock exam in the same format, for self-assessment before the real thing.

Personal work

Volume: 20 hours. Complete the exercises associated with each part of the course (Excel Fundamentals, Univariate Data Treatment, Bivariate Data Treatment) between sessions — every session page’s collapsible exercises are designed for exactly this.
