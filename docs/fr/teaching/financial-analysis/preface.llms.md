This website host all materials, and more, covered in a 3 days in-person course transitionning from *traditional* top down presentation to a *more* active teaching method.

The purpose is multiple:

1.  Being able to add or remove element during these 3 days teaching allowing more flexibility depending of student needs.
2.  24/7 avalaiblity of material so student can access it whenever and wheneverthey want/need.
